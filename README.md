# 公铁联运箱货凭证与责任交接

跟踪公铁联运货批、箱号、单证、节点回执和责任交接。

## 参与方与事实

主要参与方包括枢纽运营方、仓储企业、铁路承运方、公路承运方、海关与货代。领域资料记录以下已经确认的事实：

- 广州国际港与增城西站推进公铁联运枢纽建设
- 设施包含铁路集装箱货场和多式联运仓库
- 枢纽探索一单制和多式联运衔接

## 业务约束

- 订单箱货谱系
- 拆并守恒
- 节点回执
- 异常冻结
- 责任交接

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/intermodal_context.py` 负责读取和校验这些资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
